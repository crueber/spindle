Traffic is not measured

spindle keeps no git access log, so clone, fetch and view counts do not exist and this page does not invent them. CI has the same limit: these are the git-derived and bucket-stored facts above, nothing else.

What does exist is shown above: commit activity, authors, line churn, issue/PR states, stars/watchers/forks, releases, package tags and Threads runs.
